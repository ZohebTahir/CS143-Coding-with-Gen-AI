## Cycling through new employee talent while presevering the first 3 hires (founders of the company)
The problem that we want to solve is cycling through old employees and replacing them with new hires. However, we want to preserve the first 3 hires as those are the founders of the company. We want to use one stack and one queue, all using OOP princples. All of the code should be on one page.
